# Corporate Atlas web application

See [readme_ui.md](readme_ui.md) for full installation and configuration.

```bash
python -m pip install -r requirements.txt
npm --prefix src/ui ci
npm --prefix src/ui run build
python run_app.py
```

Interface: http://127.0.0.1:8501

API documentation: http://127.0.0.1:8501/docs

The React frontend uses same-origin HTTP requests. FastAPI owns jobs, local data,
and subprocesses running the filing/index/query modules. The production React
bundle is served by FastAPI, with no extra frontend process. Node.js is needed
for the npm build and development server, not for serving an existing build.

| Endpoint | Purpose |
| --- | --- |
| `GET /` | Compiled React interface |
| `GET /health` | Backend readiness |
| `GET /ui-health` | React build readiness |
| `GET /status` | Current job and local artifact inventory |
| `POST /prepare` | Download and paced vector workflow |
| `POST /query` | Ask a question using saved context |
| `GET /jobs/current` | Most recent job |
| `GET /jobs/{id}` | Job progress, output, and completion status |
| `POST /jobs/{id}/cancel` | Cancel a query/preparation; deletion is not cancellable |
| `GET /filings` | Downloaded fiscal quarters and index availability |
| `POST /filings/delete` | Delete explicitly selected ticker/accession pairs |
| `GET /companies/{ticker}/label` | Filing registrant name |
| `GET /usage` | Token usage totals |
| `GET /research/catalog` | Companies with indexed Chroma content |
| `GET /research/companies/{ticker}` | Chroma-backed public profile and annual facts |
| `GET /research/companies/{ticker}?refresh=true` | Refresh Wikimedia/SEC snapshots |
| `POST /research/companies` | Prepare and index a ticker (background job) |
| `POST /research/query` | Answer using selected public profiles and available RAG evidence |

Long actions return HTTP 202 with a job ID. The interface polls its status; 202
means accepted, not completed. Completed query jobs expose a cleaned `answer`
field as well as original `output`. One preparation and one query can run concurrently. A second download is
rejected until preparation finishes. Query cancellation never stops preparation.

Keep the server on localhost. There is no authentication, multi-user isolation,
persistent job queue, or restart recovery. Recent job history is bounded and held
in memory. Existing CLI modules remain runnable separately; do not run index
writes concurrently with API jobs.

Python source is installed with the editable project requirement. React uses
`src/ui/package.json` and `package-lock.json`. Use `npm ci` for repeatable installs.

The research dashboard uses Wikimedia's public summary API for general company
information and SEC company facts for annual charts. Refreshes are read-only
provider requests; downloaded snapshots are indexed and read from Chroma.
Cached JSON files are staging data, not the authority for company availability.
No market-price or future-return estimates are generated by these chart APIs.
